# Telegram-бот, отвечающий вместо тебя (Railway)

Работает через Telegram Business: бот подключается к твоему аккаунту и отвечает клиентам в личных чатах от твоего имени. Нужен Telegram Premium.

## 1. Бот и ключи
1. @BotFather → /newbot → токен. Затем /mybots → твой бот → Bot Settings → Business Mode → включить.
2. Свой user id: напиши @userinfobot.
3. Ключ Anthropic API: console.anthropic.com.

## 2. Railway
1. Залей папку в GitHub-репозиторий (или `railway up`).
2. Railway → New Project → Deploy from GitHub repo. Добавь сервис **PostgreSQL**.
3. В Variables бота: `BOT_TOKEN`, `ANTHROPIC_API_KEY`, `OWNER_ID`, `DATABASE_URL = ${{Postgres.DATABASE_URL}}`.
4. Реплика должна быть одна (polling).

## 3. Подключение к аккаунту
Telegram → Настройки → Telegram для бизнеса → Чат-боты → выбрать бота и чаты, где он работает.

## 4. Проверка стиля до запуска
Напиши боту в личку: `/try Добрый день, скиньте акт по последней поставке` — он покажет, как бы ответил клиенту. Клиентам ничего не уходит.

## 5. Стиль
- `style.md` — правила стиля (уже снято с твоего messages.html) и раздел «Факты». Допиши минималки, сроки, размеры, ткани, доставку.
- `examples.json` — 48 пар «клиент → твой ответ» из твоей переписки (имена, контакты, коды, темы про ИИ/ботов отфильтрованы). Бот подмешивает похожие примеры в каждый запрос.
- Добавить ещё переписок: `pip install beautifulsoup4`, затем
  `python import_chats.py --me "Адилет" messages.html другой.html` (или JSON с `--me ТВОЙ_ID`). Закоммить и задеплой.
  Чем больше разных чатов (цены, заказы, ассортимент, споры), тем точнее стиль. Сейчас примеры почти только про документы и маркировку.

## 6. Режимы (команды боту в личке)
- `/draft` (по умолчанию) — бот присылает тебе черновик с кнопками «Отправить / Пропустить». Можно ответить на сообщение своим текстом.
- `/auto` — отвечает сам.
- `/on` `/off` `/status` `/try`.

## Что бот НЕ отправляет клиенту сам (приходит тебе)
- любые вопросы про имя, «кто вы», «вы бот?», «живой человек?»;
- всё, где упоминается запретное слово (по умолчанию «галин…», список в переменной `FORBIDDEN_WORDS`, через запятую);
- сообщения только с вложением (фото/файл/голосовое);
- цена (бот ставит `""`), оплата, скидки, споры, вопросы вне раздела «Факты».

## Защита от «палева» в ответах бота
Перед отправкой каждый ответ проверяется: нет ли имён (клиента и любых распространённых), запретных слов, фраз ИИ/бота и шаблонной вежливости («чем могу помочь», «мне нельзя», «не могу обсуждать»), нет ли слишком длинного текста. Если не прошёл — один раз переписывается, если снова не прошёл — уходит тебе, клиент ничего не видит.
